# 💻 Ekskul Coding

Selamat datang di repository **Ekskul Coding**! 🎉

Repository ini digunakan sebagai tempat untuk menyimpan materi, latihan, tugas, dan berbagai project yang dibuat selama kegiatan ekstrakurikuler coding.

## 📚 Tentang

**Ekskul Coding** adalah wadah untuk belajar dan mengembangkan kemampuan di bidang pemrograman, teknologi, dan pengembangan software.

Di sini kita belajar bersama, mencoba hal baru, membuat project, dan tentunya tidak takut dengan error. 😄

## 🎯 Tujuan

* Mempelajari dasar-dasar pemrograman
* Meningkatkan kemampuan problem solving
* Membuat project sederhana hingga kompleks
* Mengenal berbagai teknologi dan tools
* Membiasakan diri menggunakan Git dan GitHub
* Membangun portofolio dari hasil project

## 🚀 Cara Menggunakan Repository

Clone repository ini ke komputer:

```bash
git clone https://github.com/USERNAME/ekskul-coding.git
```

Masuk ke folder repository:

```bash
cd ekskul-coding
```

Kemudian pilih materi, latihan, atau project yang ingin dipelajari.

## 🤝 Kontribusi

Anggota ekskul dipersilakan untuk berkontribusi dengan:

1. Membuat branch baru
2. Menambahkan atau memperbaiki materi
3. Membuat project
4. Melakukan commit
5. Membuat Pull Request

Contoh:

```bash
git checkout -b fitur/project-baru
git add .
git commit -m "Menambahkan project baru"
git push origin fitur/project-baru
```

## 📌 Aturan

* Gunakan repository dengan bertanggung jawab.
* Jangan menghapus atau mengubah karya orang lain tanpa izin.
* Gunakan commit message yang jelas.
* Jika menggunakan kode dari sumber lain, cantumkan sumbernya.
* Jangan takut bertanya ketika mengalami error. 😄
